# ✨ Nail Salon ✨

A gentle, ad-free nail painting game made for little kids (about 5 years old).

- **No ads. No paywalls. No sign-ups.** Just paint and play.
- Runs in any web browser — on a computer, phone, or tablet.
- Big, friendly buttons and soft colors designed for small hands.

## How to play

1. Open `index.html` in a web browser.
2. Tap a **color** or a **sticker** at the bottom.
3. Tap a **nail** to paint or decorate it.
4. Tap **Start over** to try a new design.

## Run it

Just double-click `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Put it on a phone or tablet

Because it's a normal web page, you can:
- Copy this folder to the device and open `index.html`, or
- Host the folder anywhere (GitHub Pages, Netlify, etc.) and open the link, then
- Use the browser's **"Add to Home Screen"** to make it feel like an app.
